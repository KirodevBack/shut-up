first release :3

- tray icon with a **shut it up** menu, tick discord or spotify to calm them down.
- on windows it's efficiency mode (idle priority + ecoqos) and it empties their ram.
- works on linux too (`SCHED_IDLE`, nice 19, idle io, ram paged out).
- a `config.ini` to add your own apps.
- installer for windows, no admin needed, starts with your pc.

grab `shut-up-setup.exe` for windows or `shut-up-linux-x86_64` for linux.
