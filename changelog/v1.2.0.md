cache + more apps

- **vider la ram en cache**: new button in the menu that empties the cached ram of the whole pc. it shows a warning first because some stuff can stutter for a few seconds after, so don't do it in game. it asks for admin rights.
- apps that aren't running or aren't installed now have a ⚠ next to them in the menu.
- **claude** and **visual studio code** are in the menu by default.

heads up for vs code: its exe is just `code.exe`, so if another app runs as `code.exe` it'll get shut up too.

already have a `config.ini`? the new apps won't show up on their own: delete it and shut up makes a new one, or add these yourself:

```ini
[Claude]
processes = claude

[Visual Studio Code]
processes = code
```
